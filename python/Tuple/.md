----------------------------------------------------------
1. Tuple Packing
----------------------------------------------------------

Core Logic
- Storing multiple values into a single tuple.

Syntax
```python
t = (value1, value2, value3)
```

Example
```python
fruits = ("apple", "banana", "cherry")
```

Interview Points
- Multiple values are packed into one tuple.
- Tuple is immutable after creation.

----------------------------------------------------------
2. Tuple Unpacking
----------------------------------------------------------

Core Logic
- Extract tuple values into separate variables.

Syntax
```python
a, b, c = tuple_name
```

Example
```python
fruits = ("apple", "banana", "cherry")

x, y, z = fruits
```

Interview Points
- Number of variables must equal number of tuple values.
- Used for clean and readable code.

----------------------------------------------------------
3. Using Asterisk (*)
----------------------------------------------------------

Core Logic
- Collects remaining values into a list.

Syntax
```python
a, b, *c = tuple_name
```

Example
```python
fruits = ("apple","banana","cherry","strawberry","raspberry")

x, y, *z = fruits
```

Output
```python
x = apple
y = banana
z = ["cherry", "strawberry", "raspberry"]
```

Interview Points
- * always stores remaining values as a LIST.
- * can be used in middle or last variable.
- Useful when tuple size is unknown.

----------------------------------------------------------
4. Loop Through Tuple (for Loop)
----------------------------------------------------------

Core Logic
- Iterate directly over tuple elements.

Syntax
```python
for item in tuple_name:
```

Example
```python
for x in fruits:
    print(x)
```

Interview Points
- Simplest and most common way.
- No index required.

----------------------------------------------------------
5. Loop Using Index
----------------------------------------------------------

Core Logic
- Access elements using index numbers.

Syntax
```python
for i in range(len(tuple_name)):
```

Example
```python
for i in range(len(fruits)):
    print(fruits[i])
```

Interview Points
- Uses range() + len().
- Required when index is needed.

----------------------------------------------------------
6. Loop Using while
----------------------------------------------------------

Core Logic
- Traverse tuple manually using index.

Syntax
```python
i = 0

while i < len(tuple_name):
    print(tuple_name[i])
    i += 1
```

Interview Points
- Index must be updated manually.
- Useful for custom looping conditions.

==========================================================
Tuple Methods
==========================================================

Only 2 Built-in Methods

----------------------------------------------------------
1. count()
----------------------------------------------------------

Core Logic
- Counts occurrences of a value.

Syntax
```python
tuple.count(value)
```

Example
```python
t = (1,2,2,3)

t.count(2)
```

Output
```python
2
```

Interview Points
- Returns occurrence count.
- Return Type → int

----------------------------------------------------------
2. index()
----------------------------------------------------------

Core Logic
- Returns first index of a value.

Syntax
```python
tuple.index(value)
```

Example
```python
t = ("a","b","c")

t.index("b")
```

Output
```python
1
```

Interview Points
- Returns first matching index only.
- Raises ValueError if value is not found.

## Topic: Escape Characters

```text
Escape characters use a backslash (\) to insert special or illegal characters inside a string.
```

### Common Escape Characters

| Escape | Meaning |
|---------|---------|
| \' | Single Quote |
| \" | Double Quote |
| \\ | Backslash |
| \n | New Line |
| \t | Tab |
| \r | Carriage Return |
| \b | Backspace |
| \f | Form Feed |

```python
txt = "We are the so-called \"Vikings\" from the north."

print(txt)

# Output:
# We are the so-called "Vikings" from the north.
```

## Topic: String Methods

```text
String methods are built-in functions used to perform operations on strings.
Almost all methods return a new string and do not modify the original string.
```

### Most Used String Methods

| Method | Purpose |
|---------|---------|
| upper() | Converts to uppercase |
| lower() | Converts to lowercase |
| strip() | Removes leading & trailing spaces |
| replace() | Replaces specified text |
| split() | Splits string into a list |
| find() | Returns first index of value (-1 if not found) |
| index() | Returns first index (Error if not found) |
| count() | Counts occurrences |
| startswith() | Checks starting text |
| endswith() | Checks ending text |
| capitalize() | First letter uppercase |
| title() | First letter of every word uppercase |
| swapcase() | Swaps upper & lower case |
| join() | Joins iterable elements into a string |

```python
text = "hello world"

print(text.upper())
print(text.count("l"))
print(text.startswith("he"))

# Output:
# HELLO WORLD
# 3
# True
```

## Topic: Boolean

```text
A Boolean represents one of two values:
True or False.

The bool() function converts any value into its Boolean equivalent.
```

```python
print(bool("Hello"))
print(bool(15))

# Output:
# True
# True
```

## Topic: False Values

```text
The following values evaluate to False:

False
None
0
0.0
''
()
[]
{}
set()
```

```python
print(bool(""))
print(bool([]))
print(bool(0))

# Output:
# False
# False
# False
```

---

## Topic: Objects Evaluating to False

```text
A user-defined object also becomes False if its __len__() method returns 0.
```

```python
class MyClass:
    def __len__(self):
        return 0

obj = MyClass()

print(bool(obj))

# Output:
# False
```

---

## Topic: isinstance()

```text
The isinstance() function checks whether an object belongs to a specified data type.
It returns True or False.
```

```python
x = 200

print(isinstance(x, int))

# Output:
# True
```

### Quick Interview Points

```text

✔ Empty values evaluate to False.
✔ Non-empty values evaluate to True.
✔ isinstance() checks the data type of an object.
✔ String methods return new values; they do not change the original string.
✔ Escape characters always begin with a backslash (\).
```

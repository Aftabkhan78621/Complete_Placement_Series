# Python Notes

## Topic: Upper Case

```text
The upper() method converts all characters of a string into uppercase letters.
It returns a new string and does not change the original string.
```

```python
a = "Hello, World!"
print(a.upper())

# Output:
# HELLO, WORLD!
```

---

## Topic: Lower Case

```text
The lower() method converts all characters of a string into lowercase letters.
It returns a new string without modifying the original string.
```

```python
a = "Hello, World!"
print(a.lower())

# Output:
# hello, world!
```

---

## Topic: Remove Whitespace

```text
The strip() method removes leading and trailing whitespace from a string.
Spaces between words are not removed.
```

```python
a = " Hello, World! "
print(a.strip())

# Output:
# Hello, World!
```

---

## Topic: Replace String

```text
The replace() method replaces a specified part of a string with another string.
It returns a new string.
```

```python
a = "Hello, World!"
print(a.replace("H", "J"))

# Output:
# Jello, World!
```

---

## Topic: Split String

```text
The split() method divides a string using a separator and returns a list.
```

```python
a = "Hello, World!"
print(a.split(","))

# Output:
# ['Hello', ' World!']
```

---

## Topic: String Concatenation

```text
Concatenation means joining two or more strings using the + operator.
```

```python
a = "Hello"
b = "World"

print(a + b)
print(a + " " + b)

# Output:
# HelloWorld
# Hello World
```

---

## Topic: String Format

```text
Strings and numbers cannot be joined directly using +.
Use f-strings or format() to combine them.
```

```python
age = 36
txt = "My age is " + age

# Output:
# TypeError
```

---

## Topic: F-Strings

```text
F-Strings (Python 3.6+) are the preferred way to format strings.
Use f before the string and {} for variables or expressions.
```

```python
age = 36
print(f"My age is {age}")

# Output:
# My age is 36
```

---

## Topic: Placeholders and Modifiers

```text
Placeholders {} can contain variables, expressions, functions, and format modifiers.
Use :.2f to display a float with 2 decimal places.
```

```python
price = 59

print(f"The price is {price:.2f} dollars")
print(f"The price is {20 * 59} dollars")

# Output:
# The price is 59.00 dollars
# The price is 1180 dollars
```

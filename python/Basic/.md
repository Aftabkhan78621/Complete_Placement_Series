# Python Notes

## 1. What is Python?
Python is a high-level, interpreted, general-purpose programming language.
- Created by Guido van Rossum
- Released in 1991
- Easy to learn and read
- Open-source and cross-platform

---

## 2. Uses of Python
Python is used for:
- Web Development
- Software Development
- Data Analysis
- Artificial Intelligence
- Machine Learning
- Automation (Scripting)
- Mathematics
- Cyber Security
- Desktop Applications

---

## 3. What Can Python Do?
- Create web applications
- Automate repetitive tasks
- Connect to databases
- Read and write files
- Handle large datasets
- Perform complex calculations
- Build AI and ML applications
- Rapid prototyping
- Production-ready software development

---

## 4. Why Python?
Advantages of Python:
- Works on Windows, Linux, macOS, Raspberry Pi, etc.
- Simple English-like syntax
- Requires fewer lines of code
- Interpreted language (no compilation required)
- Supports:
  - Procedural Programming
  - Object-Oriented Programming (OOP)
  - Functional Programming

## 6. Python Syntax
Python syntax is designed for readability.
Characteristics:
- Uses indentation instead of curly braces {}
- Uses new lines to end statements
- Easy to understand
- Similar to English language

Example:
```python
print("Hello, World!")
```

Output:
```
Hello, World!
```

---

## 7. Python Version
Check installed Python version:
```python
import sys
print(sys.version)
```

---
## 8. Python Command Line
Open Command Prompt or Terminal.
Start Python:
```cmd
python
```

If it doesn't work:
```cmd
py
```

Example:
```python
>>> print("Hello, World!")
```

Output:
```
Hello, World!
```

Exit Python:
```python
exit()
```

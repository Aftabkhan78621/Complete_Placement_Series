# 1. Python Basics
# -------------------------

1. What is Python?

Python is a high-level, interpreted, general-purpose programming language. It has simple and readable syntax, which makes it easy to learn and use. Python is widely used in web development, data analysis, AI, and automation. For example, I can use Python to analyze company sales data.

2. What are the features of Python?

Python has many useful features such as simple syntax, readability, portability, dynamic typing, object-oriented programming, and a large collection of libraries. It also supports multiple programming styles. For example, using Pandas, I can easily read, clean, and analyze an Excel or CSV file.

3. What are the advantages of Python?

The main advantages of Python are its simple syntax, faster development, large library support, portability, and strong community support. It also reduces the amount of code required for many tasks. For example, I can create an automation script in Python with fewer lines compared to many other languages.

4. What are the disadvantages of Python?

Python has some disadvantages as well. It is generally slower than languages like C++ because of its execution process. It can also consume more memory and may not be suitable for highly performance-critical applications. For example, C++ can be a better choice for developing high-performance game engines.

5. What are the applications of Python?

Python is used in many fields such as web development, data analysis, machine learning, artificial intelligence, automation, testing, and scientific computing. It has libraries like Pandas, NumPy, and TensorFlow. For example, as a data analyst, I can use Python and Pandas to analyze customer and sales data.

6. Is Python interpreted or compiled?

Python is mainly considered an interpreted language, but internally it also uses a compilation step. Python source code is first converted into bytecode, which is then executed by the Python Virtual Machine. For example, when I run a Python program, I normally don't manually compile it before execution

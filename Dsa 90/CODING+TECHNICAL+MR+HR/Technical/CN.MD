COMPUTER NETWORKS TOP 50 INTERVIEW QUESTIONS
===========================================================

1. What is a Computer Network?
A computer network is a group of connected devices that communicate and share resources such as files, printers, and internet access. It makes communication and collaboration easier. For example, in my college lab, all computers were connected through a local network, allowing students to use the same internet connection and shared printer efficiently.

2. What are the Advantages of Computer Networks?
2. Computer networks make it easy to share files, printers, and internet connections, reducing cost and improving communication. They also support teamwork by allowing users to access shared resources quickly. For example, in my college lab, students used the same network printer and internet connection efficiently.

3. What is LAN?
3. LAN, or Local Area Network, connects devices within a small area such as a home, school, or office. It provides fast communication and resource sharing. For example, my college computer lab uses a LAN to connect all systems, enabling file sharing and internet access.


4. What is WAN?
4. WAN, or Wide Area Network, connects devices across large geographical areas, such as different cities or countries. It links multiple LANs together. The internet is the best example of a WAN because it allows people around the world to communicate and share information.

5. What is MAN?
MAN, or Metropolitan Area Network, connects multiple LANs within a city or a large campus. It covers a bigger area than a LAN but is smaller than a WAN. For example, a university with multiple campuses in the same city can use a MAN.

6. What is Network Topology?
Network topology is the physical or logical layout of how devices are connected in a network. It affects communication and performance. For example, many offices use a star topology because it is easy to manage and troubleshoot if a device fails.

7. What is Bus Topology?
Bus topology is a network setup where all devices are connected to a single main cable called the bus. Data travels through this cable to reach devices. It is simple and low-cost but difficult to manage if the main cable gets damaged.

8. What is Star Topology?
Star topology is a network where all devices are connected to a central device, such as a switch or hub. It is reliable because one device failure does not affect others. For example, most office and college computer labs use a star topology.


9. What is Ring Topology?
Ring topology is a network where each device is connected to two other devices, forming a circular path. Data travels from one device to another until it reaches the destination. It is organized, but if one connection fails, communication can be affected.

10. What is Mesh Topology?
Mesh topology is a network where devices are connected to multiple other devices, creating several communication paths. This provides high reliability because if one connection fails, data can travel through another path. It is commonly used in critical networks.

11. What is Network Architecture?
Network architecture is the overall design of a computer network, including how devices are connected and communicate. It defines the network structure, hardware, software, and protocols. For example, most organizations use client-server architecture to manage users and shared resources efficiently.

12. What is Client-Server Model?
The client-server model is a network architecture where clients request services, and a central server provides them. It improves security and resource management. For example, when I log into my college portal, my computer acts as the client while the college server provides the required data.

13. What is Peer-to-Peer Network?
A peer-to-peer network is a network where all computers have equal roles and can share resources directly without a central server. It is simple and suitable for small networks. For example, two laptops sharing files directly over the same Wi-Fi network use peer-to-peer communication.

14. What is Protocol?
A protocol is a set of rules that allows devices to communicate correctly over a network. It ensures data is sent and received in a standard way. For example, when I browse a website, HTTP or HTTPS protocols help my browser communicate securely with the web server.

15. What is OSI Model?
The OSI Model is a seven-layer reference model that explains how data moves between devices in a network. It helps understand, design, and troubleshoot network communication. For example, when browsing a website, different OSI layers handle data formatting, routing, and transmission to ensure successful communication.

16. Name the Layers of OSI Model.
The OSI Model has seven layers: Physical, Data Link, Network, Transport, Session, Presentation, and Application. These layers work together to ensure reliable communication between devices over a computer network.

17. What is Physical Layer?
The Physical Layer is the first layer of the OSI Model. It transfers raw data as electrical, optical, or wireless signals through cables or other transmission media between connected devices.

18. What is Data Link Layer?
The Data Link Layer ensures error-free data transfer between directly connected devices. It handles framing, error detection, and MAC addressing. For example, a switch uses MAC addresses to forward data correctly.

19. What is Network Layer?
The Network Layer is responsible for routing data packets from the source to the destination using IP addresses. For example, when accessing a website, this layer finds the best path for data.

20. What is Transport Layer?
The Transport Layer ensures reliable data delivery between devices. It handles error checking, flow control, and data sequencing. For example, TCP in this layer ensures files are received completely without missing data.

21. What is Session Layer?
The Session Layer establishes, manages, and terminates communication sessions between devices. It ensures that data exchange starts, continues, and ends properly. For example, it maintains the connection during a video meeting.

22. What is Presentation Layer?
The Presentation Layer translates, encrypts, and compresses data before sending it. It ensures data is in a readable format for the receiving system. For example, it encrypts data during secure online transactions.

23. What is Application Layer?
The Application Layer is the top layer of the OSI Model that provides network services directly to users. Applications like web browsers, email, and file transfer use this layer to communicate over the network.

24. What is TCP?
TCP, or Transmission Control Protocol, is a reliable communication protocol that ensures data is delivered correctly and in order. For example, downloading a file uses TCP to make sure no data is lost.

25. What is UDP?
UDP, or User Datagram Protocol, is a fast communication protocol that sends data without checking delivery. It is suitable for real-time applications. For example, online games and video streaming commonly use UDP.

26. Difference between TCP and UDP.
TCP is reliable, connection-oriented, and ensures data reaches correctly, but it is slower. UDP is faster, connectionless, and does not guarantee delivery. File downloads use TCP, while live video streaming and gaming usually use UDP.

27. What is an IP Address?
An IP Address is a unique numerical address assigned to every device on a network. It helps identify devices and route data correctly. For example, when visiting a website, data is sent using IP addresses.

28. What is IPv4?
IPv4 is the fourth version of the Internet Protocol and uses 32-bit addresses, such as 192.168.1.1. It is widely used but has a limited number of available addresses.

29. What is IPv6?
IPv6 is the latest version of the Internet Protocol and uses 128-bit addresses, providing a much larger address space. It was introduced to overcome the address limitations of IPv4.

30. What is MAC Address?
A MAC Address is a unique physical address assigned to a network interface card by the manufacturer. It identifies devices within a local network. For example, switches use MAC addresses to forward data correctly.



31. What is DNS?
DNS, or Domain Name System, converts website names into IP addresses. It helps users access websites without remembering numerical addresses. For example, typing google.com is translated into its corresponding IP address.

32. What is DHCP?
DHCP, or Dynamic Host Configuration Protocol, automatically assigns IP addresses and network settings to devices. This saves time and avoids manual configuration. For example, your laptop gets an IP address automatically when connected to Wi-Fi.

33. What is HTTP?
HTTP, or HyperText Transfer Protocol, is used to transfer web pages between a browser and a web server. It does not encrypt data. For example, older websites commonly use HTTP.

34. What is HTTPS?
HTTPS, or HyperText Transfer Protocol Secure, is the secure version of HTTP. It encrypts data exchanged between the browser and server. For example, online banking and shopping websites use HTTPS for secure communication.

35. What is FTP?
FTP, or File Transfer Protocol, is used to transfer files between computers over a network. It is commonly used to upload website files to a server during web development.

36. What is SMTP?
SMTP, or Simple Mail Transfer Protocol, is used to send emails from a client to a mail server or between mail servers. For example, Gmail uses SMTP to send outgoing emails.

37. What is POP3?
POP3, or Post Office Protocol Version 3, downloads emails from the server to a device and usually removes them from the server. It is useful when accessing emails on a single device.

38. What is IMAP?
IMAP, or Internet Message Access Protocol, allows users to access and manage emails directly from the mail server. It keeps emails synchronized across multiple devices, such as a laptop and smartphone.

39. What is Router?
A router is a networking device that connects different networks and forwards data between them. For example, the Wi-Fi router at home connects local devices to the internet.

40. What is Switch?
A switch connects multiple devices within the same local network and sends data only to the intended device using MAC addresses. It improves network performance compared to a hub.

41. What is Hub?
A hub is a basic networking device that connects multiple computers and sends incoming data to all connected devices. It is simple but less efficient because every device receives the same data.

42. What is Bridge?
A bridge is a networking device that connects two LAN segments and filters traffic using MAC addresses. It helps reduce unnecessary network traffic and improves communication between connected networks.

43. What is Firewall?
A firewall is a security system that monitors and controls incoming and outgoing network traffic based on security rules. For example, it blocks unauthorized access while allowing trusted network communication.

44. What is Bandwidth?
Bandwidth is the maximum amount of data that can be transferred over a network in a given time. Higher bandwidth allows faster data transfer. For example, a high-speed internet connection supports smoother video streaming.

45. What is Latency?
Latency is the time taken for data to travel from the sender to the receiver over a network. Lower latency means faster communication. For example, online gaming and video calls require low latency for a smooth experience.

46. What is Packet?
A packet is a small unit of data sent across a network. Large files are divided into packets and reassembled at the destination. This makes data transmission more efficient and reliable.

47. What is Routing?
Routing is the process of selecting the best path to send data from the source to the destination. Routers perform this task using routing tables. For example, internet data reaches websites through routing.

48. What is Congestion?
Congestion occurs when too much data travels through a network at the same time, reducing performance. It can cause delays and packet loss. For example, internet speed often slows during peak usage hours.

49. What is Network Security?
Network security is the practice of protecting a network, devices, and data from unauthorized access, attacks, and threats. For example, firewalls and encryption help keep sensitive information safe during communication.

50. What is VPN?
VPN, or Virtual Private Network, creates a secure and encrypted connection over the internet. It protects user data and privacy. For example, many companies use VPNs to allow employees to securely access office systems remotely.

BONUS QUESTIONS
===========================================================

51. Difference between Hub, Switch and Router.
A hub sends data to all connected devices, making it less efficient. A switch sends data only to the correct device using MAC addresses. A router connects different networks and forwards data using IP addresses.

52. Difference between HTTP and HTTPS.
HTTP transfers web pages without encryption, making it less secure. HTTPS encrypts data using SSL/TLS, providing secure communication. For example, banking and shopping websites use HTTPS to protect user information.

53. Difference between IPv4 and IPv6.
IPv4 uses 32-bit addresses, such as 192.168.1.1, and has limited address space. IPv6 uses 128-bit addresses, providing a much larger address range and better support for modern internet devices.

54. Difference between LAN, MAN and WAN.
LAN covers a small area like a home or office, MAN covers a city or large campus, and WAN connects networks across countries or continents. The internet is the best example of a WAN.

55. Difference between OSI Model and TCP/IP Model.
The OSI Model has seven layers and is mainly used as a reference model. The TCP/IP Model has four layers and is used in real-world internet communication. TCP/IP is more practical for modern networking.

56. Difference between MAC Address and IP Address.
A MAC Address is a permanent physical address assigned to a network card by the manufacturer. An IP Address is a logical address assigned to identify a device on a network and can change.

57. What is ARP?
ARP, or Address Resolution Protocol, maps an IP address to its corresponding MAC address within a local network. It helps devices communicate correctly before sending data to the destination.

58. What is Three-Way Handshake?
The Three-Way Handshake is the TCP process used to establish a reliable connection. It involves SYN, SYN-ACK, and ACK messages, ensuring both devices are ready before data transmission begins.

59. What is Socket?
A socket is a communication endpoint used by applications to send and receive data over a network. It combines an IP address and a port number to establish communication between devices.

60. What is Port Number?
A port number is a logical number that identifies a specific application or service on a device. For example, HTTP uses port 80, while HTTPS uses port 443 for secure web communication.
